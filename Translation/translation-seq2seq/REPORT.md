# 中英翻译 Seq2Seq 模型实验报告

## 1. 实验概述

基于 GRU 的 Seq2Seq 模型实现中英翻译，对比**无 Attention** 和 **含 Attention** 两种架构效果。

## 2. 模型架构

| 组件 | 配置 |
|------|------|
| 编码器 | 2 层单向 GRU，hidden_size=256 |
| 解码器 | 4 层单向 GRU，hidden_size=256 |
| 词嵌入 | embedding_dim=128 |
| 注意力 | 无 / 点积注意力 |
| 词表 | 中文 ~2000 词，英文 ~54687 词 |

## 3. 数据

| 数据集 | 来源 | 句数 |
|--------|------|------|
| cmn.txt | Tatoeba | ~2.9 万 |
| bigger_data.csv | 扩展语料 | ~26.2 万 |
| **合并总数** | | **~29.1 万** |
| 训练集 (80%) | | ~23.3 万 |
| 测试集 (20%) | | ~5.8 万 |

## 4. 训练配置

| 参数 | 值 |
|------|-----|
| 优化器 | Adam |
| 学习率 | 1e-3 |
| Batch Size | 64 |

| 训练轮数 | 50 |
| 单轮耗时 | ~5 分钟 |
| 总耗时 | ~4 小时 |

|------|------|
| 无 Attention | **0.108** |
| 有 Attention | **0.136** |
| 提升 | **+26%** |

## 7. 分析

### 7.1 Attention 效果

- **BLEU 提升 26%**，证明 Attention 机制有效
- 对中等长度句子（含多义动词、否定、从句）提升明显
- 部分短句反而出现词序错乱，说明 Attention 还需要更多训练

### 7.2 模型局限性

1. **无预训练词向量**：词嵌入随机初始化，需要更多数据来学习语义
2. **数据量有限**：29 万句对口语够用，但远不如大模型千万级
3. **词级词表**：无法处理未登录词（OOV），时态/单复数/冠词细节丢失
4. **口语数据偏差**：`tom` 出现 3300+ 次，数据集中 Tom 例句过多

### 7.3 改进方向

| 方向 | 预期效果 |
|------|---------|
| 预训练词向量 (GloVe/Word2Vec) | 提升语义理解，减少 OOV 问题 |
| 更大规模数据 | 提升泛化能力 |
| 增大 hidden_size | 缓解信息瓶颈 |
| Transformer 架构 | 质量上限更高 |

## 8. 结论

- 4 层 GRU 解码器 + Attention 的 Seq2Seq 模型在 29 万条中英平行语料上训练 50 轮后，BLEU 达到 **0.136**
- 相比无 Attention 基线 **0.108**，提升 **26%**
- 对日常口语翻译效果良好，但复杂句和长句仍有提升空间
- 架构简单、训练快速（4 小时），适合快速验证翻译思路
